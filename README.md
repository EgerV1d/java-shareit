# Shareit

Backend ддя сервиса шеринга вещей: пользователи делятся вещами, берут их в аренду и оставляют отзывы.

## Стек

Java 21, Spring Boot, Spring Data, Hibernate, PostgreSQL, Docker, Maven, JUnit 5, Mockito.

## Что реализовано

- CRUD для вещей и пользователей
- Бронирование вещей с подтверждением / отклонением владельцем вещи
- Поиск вещей по названию и описанию
- Отзывы после завершения аренды
- Разделение доступа: владелец / арендатор
- Покрытие ключевой логики тестами
